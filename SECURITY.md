# Security

CoopInput uses low-level keyboard/mouse interception and (optionally) injects a
DLL into an attached game process. Only install trusted builds. Never run
untrusted forks with administrator privileges.

The Interception driver is a separate prerequisite. It should be obtained only
from upstream, not from third-party DLL download sites.

If you encounter an input lock-up, try the Ctrl+Alt+F12 emergency shortcut;
if that fails, disconnect the secondary device or restart Windows.

Do not submit hardware identifiers, usernames, or detailed debug logs publicly
without reviewing and redacting personal information.
